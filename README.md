# Margalla Trail Co.

CS4032 Web Programming - Assignment 02 (Business Website Development Using React).

A React website for a fictional business that runs guided hikes and outdoor day
experiences around Islamabad. All bookings are simulated.

## Commands

```bash
npm install     # install dependencies
npm run dev     # start the development server
npm run build   # create the production build
npm test        # run the business-rule tests (node --test)
```

The full README is completed as the project develops.
